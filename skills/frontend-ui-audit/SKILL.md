# Instructions

Use a real browser.

Inspect:
- CSS loading
- layout
- typography
- navigation
- cards/tables
- dark/light themes
- loading/empty/error states
- desktop/mobile
- browser console/network
- API responses

Capture screenshots before and after fixes.

Do not approve based only on HTTP 200 or successful builds.

Verify real backend data is displayed and no fake financial data is introduced.

Return PASS / PARTIAL / FAIL.
