# Instructions

Verify:
- keyboard navigation
- visible focus
- semantic headings
- form labels
- buttons/links
- accessible dialogs/popovers
- tap support for mobile
- no hover-only critical information
- basic contrast
- no horizontal overflow
- desktop/mobile layouts

Use real browser viewport testing.

Return PASS / PARTIAL / FAIL.
