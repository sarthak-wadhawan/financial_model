# Website API contract — BUILD D/J, frozen v1 (2026-10-14)

Base `/api/v1`. Frontend ownership: pages/components/styles belong to other workers; D owns `services/api.ts`. No Phase12. Arrays remain arrays (no envelope migration).

- `GET /market/overview`: `timestamp`, `snapshot_time` (retrieval, NOT market time), `market_status:"unknown"`, `symbols_tracked`, `market_data_status`, `quant_scanner_status`, `mode:"real"|"demo"`, `source`, `source_url`, `reason:string|null`, `indices` (SPY daily close, not live quote: symbol/price/change/change_pct/market_timestamp/retrieved_at/source), `top_gainers/top_losers/most_active` arrays. Unsupported VIX/DXY/yield remain unavailable, never fabricated.
- `GET /symbols/search?q=`: array `{symbol,name:string|null,exchange:string|null,type,source}`. Existing universe + SEC ticker map/provider metadata; ticker lookup does not require candidate eligibility.
- `GET /stocks/{symbol}`: `{symbol,name:null|string,exchange:null|string,price:null|number,change:null|number,change_pct:null|number,volume:null|number,market_cap:null,pe_ratio:null,dividend_yield:null,price_data,quant_signals,interpretation,events}`. Price is latest completed **daily close**, labelled by `price_data`. Metadata unknown stays null. Detail must work with empty DB/unavailable market.
- `GET /market/bars/{symbol}?timeframe=1Day&start=YYYY-MM-DD&end=...&limit=`: `{symbol,timeframe,bars:[{t,o,h,l,c,v}],status,reason,mode,source,source_url,market_timestamp,retrieved_at}`. Only daily supported; unsupported timeframe explicitly 400. Range bound and future bars excluded.
- `GET /scanner/top?n=`: array of deterministic existing scorer candidates `{symbol,rank,quant_score,momentum_score,trend_score,liquidity_score,volume_score,volatility_quality_score,price,avg_dollar_volume_20d,components,market_timestamp,calculated_at,source,mode}`. Scanner availability/reason on overview and `GET /scanner/status`. Empty is not a claim of successful scan.
- `GET /stocks/{symbol}/quant`: `{symbol,quant_score:null|number,rank:null|number,universe_size:null|number,components,signals,status,reason,source,mode,calculated_at,market_timestamp}`. No client/AI score calculations.
- Phase9 interpretation is serialized **unchanged** from existing model: separate company/stock impact, base/bull/bear, nullable probability_band, missing_information, confidence, generated_at/as_of and supporting_evidence `{evidence_id,source_type,description,url:null|string,timestamp:null|string}`. No invented probability/evidence/times.
- `POST /stocks/{symbol}/answer` body `{question,context?}` (symbol comes from path); GET `?question=` also supported. Actual Answer `{question,answer,confidence,evidence_refs:EvidenceRef[],generated_at}`; no fictional answer_id.
- Earnings/news/insider/filing/company/macro/recent/upcoming endpoints return **full MarketEvent** records, not flattened fabricated news/transaction objects: event_id,event_type,symbol nullable,title,description,scheduled_at,released_at,timezone,importance,status,actual,forecast,previous,unit,source,source_url,source_id,first_seen_at,last_seen_at,created_at,updated_at,content_hash,metadata. Provider-specific facts remain in `metadata`. Retrieval is not publication. `event_types` accepts comma-separated values; invalid types 400. Date filters use scheduled_at OR released_at; no invented dates. Stored test/fixture sources preserved and labelled, never deleted.
- Leadership `{symbol,leadership:Record<role,{name,effective_date,event_id,source,source_url,released_at}>}` evidence-derived, not permanent CEO/CFO literals.
- Terms: `/terms/search?q=` ordered before `/terms/{term}`; actual TermDefinition `{term,short_definition,long_definition:null|string,external_reference_url:null|string,reference_type,category,related_terms}`.
- Phase11 existing CRUD endpoints unchanged. Reorder POST body **`{symbols:string[]}`**. Calendar POST unchanged; GET date fields validated. Alert dry-run service owned by H; D does not invent current_values or execute external deliveries. Service ValueErrors map to safe 400 responses; missing entities 404.

Adapter internal interface: `WebsiteDataAdapter(config,settings,provider=None,mode="real")`; sync `overview()`, `search(q,limit)`, `bars(symbol,start,end,limit)`, `scan(n)`, `quant(symbol)`, `status()`; provider calls run in threadpool API endpoints. Real uses Alpaca/IEX; explicit demo only uses mock. Credentials never serialized. State: available/empty/unavailable/provider_error/stale with safe reason; source + market/retrieval/calculation timestamps distinct. Existing feature/eligibility/scorer reused unchanged.
